
# Zombie Survival Predictor

Will you survive the zombie apocalypse? Answer 8 questions. A machine learning model trained on 20 years of real US mortality data returns one number: your odds of making it out alive.

Built as a debugging target for an open-source competition. The model is intentionally imperfect. Find the bugs.

---

## Running it locally

### What you need

- Python 3.10 or higher
- Node.js 18 or higher

---

### 1. Clone the repo

```bash
git clone https://github.com/aditiakansha/zombie_survival.git
cd zombie_survival
```

### 2. Set up the Python environment

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Get the data

The raw NHANES and mortality files are included in the repo and will be present after cloning. No manual download needed.

### 4. Build the processed dataset

```bash
cd training
python data_loader.py
```

This merges the demographics and mortality files and saves a clean CSV to `data/processed/demographics_mortality_clean.csv`.

### 5. Train the models

```bash
python run_all.py
```

This trains five classifiers (Logistic Regression, Random Forest, XGBoost, SVM, KNN), prints a comparison table ranked by ROC-AUC, and saves the best model to `training/models/best_model.joblib`.

### 6. Start the API

Open a terminal in the repo root (not inside `app/`):

```bash
cd ..   # if you're still in training/
source .venv/bin/activate
uvicorn app.main:app --reload
```

The API runs at `http://127.0.0.1:8000`. Check it is alive at `http://127.0.0.1:8000/health`.

### 7. Start the frontend

Open a second terminal:

```bash
cd frontend
npm install
npm run dev
```

Go to `http://localhost:5173`. Answer 8 questions. Find out if you make it.

## How it actually works

The model has nothing to do with zombies. It is trained on NHANES demographic survey data (1999–2018) linked to CDC mortality records, and predicts the statistical likelihood that someone with your demographics was still alive by the end of the follow-up period in 2019. We are calling that your zombie survival odds.

Five models are trained and compared. The winner (usually XGBoost at around 88% AUC) is saved and served via a FastAPI endpoint. The React frontend sends your answers to that endpoint and displays the result.
